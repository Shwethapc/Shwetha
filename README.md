# Shwetha Chikkalingaiah - Portfolio Website

A modern, responsive portfolio website showcasing the skills, education, projects, and experience of Shwetha Chikkalingaiah, a Computer Science Engineering student and aspiring software developer.

## 🌟 Features

### Modern Design
- Clean, professional layout with modern UI/UX principles
- Responsive design that works perfectly on all devices (desktop, tablet, mobile)
- Beautiful gradient color scheme with blue and cyan accents
- Smooth animations and hover effects
- Professional typography using Inter font family

### Interactive Elements
- Smooth scrolling navigation with active section highlighting
- Mobile-friendly hamburger menu with animated transitions
- Contact form with validation and success/error notifications
- Scroll-triggered animations for enhanced user experience
- Interactive skill tags with ripple effects
- Parallax scrolling effects (desktop only)

### Sections
1. **Hero Section** - Eye-catching introduction with call-to-action buttons
2. **About Me** - Personal information and language proficiencies
3. **Education** - Timeline view of academic achievements
4. **Skills & Expertise** - Programming languages, tools, and certifications
5. **Featured Project** - Showcase of the Online Shopping Centre project
6. **Extra-curricular Activities** - Interests and hobbies
7. **Contact** - Contact form and information

## 🚀 Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with Flexbox, Grid, and CSS Variables
- **JavaScript (ES6+)** - Interactive functionality and animations
- **Font Awesome** - Professional icons
- **Google Fonts** - Inter font family for beautiful typography

## 🎨 Customization

To customize the portfolio for yourself:

1. **Update Personal Information** in `index.html`
   - Change name, contact details, and bio
   - Update education, skills, and certifications
   - Modify project details

2. **Adjust Colors** in `styles.css`
   - Modify CSS variables in `:root` section
   - Change the color scheme to match your preference

3. **Add Your Photo**
   - Replace the icon placeholder in hero section
   - Add your professional photo

4. **Update Content**
   - Add more projects
   - Include additional skills or experiences
   - Modify sections as needed
