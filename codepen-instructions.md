# CodePen Alternative for Your Portfolio

## Quick Setup on CodePen:

1. **Go to:** https://codepen.io/pen
2. **Click "Settings" gear icon**
3. **Go to HTML tab and add this in the HEAD:**

```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0/css/all.min.css">
```

4. **Copy each section separately:**
   - HTML goes in HTML panel
   - CSS goes in CSS panel  
   - JavaScript goes in JS panel
